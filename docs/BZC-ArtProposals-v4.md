1. **A 只用于"有故事的地方"**:历史剧舞台、乌苏里江、闯关东遗址、祭奠场景。日常活动绝不出现水墨。

4. **色板统一锚点**:两个方案共用同一套**黑土色系**(`#3B2A1E` 深壤 / `#6B4E32` 壤 / `#C8A165` 秋金 / `#8FB8DE` 冬冷蓝 / `#D9C9A3` 麻袋白 / `#4A5D3A` 苞米绿),保证 A/B 并置时不打架。

## 2. A 部分:水墨国风(40%)

### 视觉基调(黑龙江版)

> 想象:古戏台在雪夜里亮起来,台板上墨色浓重,一笔扫过是松花江的雾凇;台下的屯子里,灯笼是暖橘色,雪压着苞米楼子。国风不是江南水乡,而是**黑土地上的凛冽与厚重** —— 皴擦用焦墨重笔,留白是大片的雪。

**与 v3 的关键差异**:v3 的 A 风参考《桃源深处有人家》(江南国风)。v4 必须改为**北方国风**:硬朗、苍劲、大片留白的雪原、朴拙的木构(古戏台/供销社/粮仓)、浓墨点染的松林。

**参考素材**:北方国风插画 / 东北民间版画 / 冰雪摄影的留白构图 / 《千里江山图》的皴法(而非青绿设色)

## 3. B 部分:清新写实(60%)

### 视觉基调(黑龙江版)

> 想象:黑土地翻开后是深褐色的湿土,垄沟笔直延伸到天边;夏天是望不到头的苞米地,绿得发暗;秋天场院上摊着金色的玉米,空气里是柴火烟和晒粮的味道。主角穿卡其工装和胶靴。整体明亮、饱和但不刺眼,和 v3 的江南水田完全不同 —— **这里是平原、是大、是硬朗的线条**。

**与 v3 的关键差异**:
- v3:稻田水田 / 湿润 / 南方丘陵 / 小块
