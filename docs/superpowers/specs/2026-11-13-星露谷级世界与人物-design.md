# 《宾州小镇》星露谷级世界与人物重构设计

> 日期:2026-11-13
> 状态:**已批准** —— 制作人于 2026-11-14 批准方案 A,进入全量实装
> 取代范围:v4 的“单屏农场 + 1 名 NPC + 75/5/20 支柱”作为下一阶段主设计
> 关联:`docs/BZC-代码审查-2026-11-13.md`、`docs/BZC-人物圣经-v5.md`

---

## 1. 意图

玩家对当前版本的判断是准确的:

- **世界不像星露谷**:只有 3 个固定单屏地点,没有可滚动的大地图、没有农舍/商店/餐馆等可进入的室内空间,也没有小镇生活的空间密度。
- **画质不像饥荒**:背景是平涂色块和剪影,角色与场景缺少笔触、材质、光照、天气和季节变化。
- **玩法只有种田骨架**:采集、钓鱼、送礼、好感事件、NPC 日程、任务、节日、烹饪/冬储、农场扩建都缺失。
- **人物塑造不足**:张晓芳目前是“农时讲解器 + 收购商”,没有独立欲望、秘密、关系网和好感度驱动的完整弧线。

这次重构不是继续往单屏里加按钮,而是把项目从“种田 Demo”升级为**星露谷式小镇生活游戏的世界结构**,同时把视觉语言拉到**饥荒级手绘质感**。

---

## 2. 目标 / 非目标 / 反目标

### 2.1 目标

1. 玩家可以在大于屏幕的农场、镇中心和野外地图上自由行走,相机跟随,进入多个室内场景。
2. 一天有明确时钟、昼夜、天气;一年有四季环境变化和东北气候压力。
3. 种田之外,玩家可以采集、钓鱼、烹饪/冬储、送礼、接任务、参加节日、触发 NPC 好感事件。
4. 至少 6 名核心 NPC 拥有独立故事、日程、生日、喜恶、关系网和每人 3 个好感事件。
5. 画面达到“手绘粗墨线 + 纸纹/木刻肌理 + 四季低饱和东北土色盘”的统一质量,不再以纯程序色块作为主要视觉。
6. 所有新增系统都有纯逻辑层 headless 测试和场景验收脚本。

### 2.2 非目标(本轮不做)

- 不在本轮追求 38 名 NPC、200 张明信片、完整婚姻系统、矿洞战斗、畜牧全产业链。
- 不用 AI 图直接充当可动画的最终 sprite sheet。
- 不把游戏改成 3D 或低多边形。
- 不为了“像星露谷”照搬其具体美术、角色或地图布局。

### 2.3 反目标

- **只扩场景、不填生活**:走进去只有空地、没有人物和互动,不算完成。
- **只加对白条数、不加人物弧线**:对话数量不是人物塑造。
- **继续用平涂色块冒充手绘**:截图验收不过关就不进入全量铺量。

## 3. 方案选择

### 方案 A:世界结构与人物双主线重构(推荐)

以“完整核心生活循环”为目标:11 个可进入场景、6 名深写 NPC、18 个好感事件、时钟/天气/四季、采集/钓鱼/烹饪/送礼/任务/节日。按里程碑分批交付,每个里程碑都必须可玩、可存档、可验收。

**优点**:直接回应五项要求;新系统可以互相供给内容(季节→采集→烹饪→送礼→事件→节日)。**代价**:内容量大,必须先修 P0/P1 再扩展。

### 方案 B:两季垂直切片

只做农场、农舍、镇中心 3 张地图、2 名 NPC、春冬两季,验证质量后再扩。

**优点**:最快看到质量。**缺点**:无法满足“该有的场景和玩法都存在”的要求;世界仍然空。作为风险控制手段可以内嵌在方案 A 的 M1/M2 里,但不作为最终范围。

### 方案 C:美术优先,先铺大图

先做 11 张漂亮地图和角色立绘,再做玩法。

**优点**:首屏冲击强。**缺点**:会得到一座不能生活的空镇,且玩法返工会推翻地图布局。**不采用**。

**结论:采用方案 A,并用方案 B 的切片方式控制每个里程碑的风险。**

## 4. 新四支柱

| 支柱 | 占比 | 玩家行为 | 对应世界内容 |
|---|---:|---|---|
| **黑土地生活** | 35% | 翻土、播种、浇水、收获、秋翻、扩建、采集、钓鱼、冬储 | 农场、农舍、河岸、桦树林 |
| **小镇社会** | 25% | 买东西、吃饭、看病、修工具、寄信、接委托、参加集市 | 镇中心、杂货店、邮局、饭馆、卫生所、木工房 |
| **人物故事** | 25% | 观察日程、送礼、聊天、触发好感事件、做人物委托 | 6 名核心 NPC、18 个事件、关系网 |
| **季节活动** | 15% | 春耕、夏汛、秋收、冬歇;节日与年货 | 四季环境、2 个节日、古戏台演出 |

历史剧/二人转不再单独占 20% 成为割裂模块,而是变成**古戏台与人物故事、季节活动的一部分**。

## 5. 世界模型

### 5.1 取景与视角

- **视角**:3/4 俯视,角色四方向行走,场景可滚动。
- **基准分辨率**:1920×1080。
- **世界网格**:64×64 像素瓦片;角色约 96×144 像素,屏幕占比约 13%。
- **相机**:跟随主角,带平滑与地图边界钳制;对话/面板打开时角色与相机停住。
- **UI**:固定屏幕空间,不随世界滚动;农时、日期、天气、金币、体力常驻但降噪。
- **地图尺寸**:主地图 3-4 屏,室内 1-2 屏;不再用固定 960×540 单屏。

### 5.2 地图层级

每个地图统一为以下节点结构:

```text
MapRoot
├── Ground            地面瓦片 / 道路 / 雪层
├── PropsBehind       树冠后层、建筑背墙、篱笆后层
├── Entities          Player / NPC / 可交互物 / 碰撞体
├── PropsFront        前景树、门框、遮挡物
├── Weather           雨雪、风、雾、落叶
├── Lighting          昼夜色罩、窗光、篝火/灯
└── Triggers          门、区域、事件触发
```

前景遮挡和光照必须分开,否则角色会被“画死”在地图里。

### 5.3 场景清单

| ID | 场景 | 尺寸(世界像素) | 核心功能 | 必须存在的内容 |
|---|---|---:|---|---|
| L01 | 自家农场 | 3200×2240 | 种田、扩建、加工、天气 | 可扩建农田、水井、柴垛、院门、农舍入口 |
| L02 | 农舍室内 | 1280×896 | 睡觉、储物、烹饪、看预报 | 火炕、灶台、柜子、日历、天气预报 |
| L03 | 镇中心 | 3840×1920 | 社交、集市、公告、节日 | 公告板、摊位、广场、通往各商铺的门 |
| L04 | 杂货店 | 1280×896 | 买种子/工具/礼物 | 柜台、货架、老板 NPC、营业时间 |
| L05 | 老邮局 | 1280×896 | 寄信、明信片、人物事件 | 柜台、邮件格、韩守义工作日程 |
| L06 | 玉梅饭馆 | 1536×1024 | 吃饭回体力、打听消息、节日聚餐 | 灶台、桌子、菜单、孙玉梅日程 |
| L07 | 镇卫生所 | 1280×896 | 受伤/疲劳处理、林小满剧情 | 诊台、药柜、候诊椅 |
| L08 | 赵家木工房 | 1280×896 | 农场扩建、工具升级、家具 | 工作台、木料、半成品、赵长河日程 |
| L09 | 河岸 | 2560×1280 | 钓鱼、夏汛、冬捕前置 | 河面、码头、芦苇、鱼点 |
| L10 | 桦树林 | 2560×1600 | 采集、蘑菇、柴火、迷路事件 | 桦树、倒木、蘑菇点、采集刷新 |
| L11 | 古戏台 | 1920×1280 | 二人转、节日、周德顺故事 | 戏台、后台、乐器、观众席 |

**门与地点切换**:不再用 `F/P` 直接瞬移;玩家走到门口/地图边缘触发区域后切换。保留调试快捷键,但正式体验以空间移动为主。

### 5.4 世界关系

```text
            桦树林
              │
   农场 ─── 河岸 ─── 古戏台
     │        │          │
   农舍     镇中心 ──────┘
              │
   杂货店 / 邮局 / 饭馆 / 卫生所 / 木工房
```

镇中心是所有生活服务的枢纽;农场与野外提供原料;古戏台承载公共活动和人物高光。

## 6. 时间、天气与季节

### 6.1 游戏时钟

- 一天从 **06:00** 开始,最晚到 **26:00(次日 02:00)**。
- 默认 **1 游戏分钟 = 0.9 现实秒**,完整一天约 **18 现实分钟**。
- 对话、背包、商店、事件选择时暂停时钟;走路、干活、钓鱼时继续。
- 02:00 未睡:强制昏倒,次日体力上限暂时下降;不死亡、不删档。
- 睡觉不是“按 T 直接跳天”:必须回到农舍火炕,或触发野外露营点(后续)。

### 6.2 一天的行为段

| 时段 | 时间 | 用途 |
|---|---|---|
| 清晨 | 06:00-08:00 | 看天气、收信、赶集、NPC 出门 |
| 上午 | 08:00-12:00 | 农活、商店营业、诊所开门 |
| 正午 | 12:00-14:00 | 饭馆午市、NPC 休息 |
| 下午 | 14:00-18:00 | 采集、钓鱼、木工房、跑腿 |
| 黄昏 | 18:00-21:00 | 社交、饭馆晚市、好感事件窗口 |
| 夜晚 | 21:00-26:00 | 夜市/戏台/回家;部分 NPC 已回家 |

### 6.3 天气

| 季节 | 常见天气 | 机制效果 |
|---|---|---|
| 春 | 晴、阴、细雨、倒春寒、大风 | 雨天自动浇水;倒春寒可伤害已出苗作物 |
| 夏 | 晴、闷热、雷雨、暴雨 | 雷雨自动浇水但可能吹倒作物;高温增加浇水需求 |
| 秋 | 晴、霜晨、阴、冷雨、初雪 | 霜晨触发晚收警告;冷雨降低体力恢复 |
| 冬 | 晴冷、雪、暴风雪、烟霾 | 户外体力消耗增加;暴风雪限制远行;室内火炕恢复更高 |

天气由“季节权重表 + 存档种子 + 绝对日”决定,同一天读档天气不变;前一天可看预报,但不是 100% 准确(冬季暴风雪预警更可靠)。

### 6.4 四季环境

- **春**:冻土返浆、泥泞、残雪、柳芽、屋檐滴水;主色是湿黑土、灰绿、淡黄。
- **夏**:浓绿、强光、长草、河面反光、雷雨云;主色是深绿、麦黄、湿木色。
- **秋**:金黄、灰蓝、霜白、场院、玉米楼子;主色是土金、赭红、冷灰。
- **冬**:蓝灰雪原、暖窗光、烟囱白烟、冰面、火炕室内;主色是雪青、炭黑、暖橘。

季节切换必须同时替换:地面材质、树/草、环境音、天气粒子、光照色、NPC 服装、UI 节气提示。不能只换 HUD 文字。

## 7. 玩法矩阵

| 系统 | 首个可玩版必须做到 | 验收标准 | 后续扩展 |
|---|---|---|---|
| 种田 | 可扩建农田、翻土/浇水/播种/收获、秋霜、秋翻、复种 | 一季内完成播种到收获;扩地有成本和动画 | 灌溉、温室、品质 |
| 采集 | 河岸/桦树林四季刷新 12 种山货 | 每个季节至少 3 个采集点可互动 | 稀有刷新、天气影响 |
| 钓鱼 | 河岸鱼点 + 简单力度/时机小游戏 + 8 种鱼 | 能钓到、能卖、能做菜;不同季节鱼不同 | 鱼竿升级、冬捕 |
| 烹饪/冬储 | 12 个配方;饭馆学配方;酸菜/冻货冬储 | 食材→做菜→回体力/送礼完整闭环 | 加工坊、批量制作 |
| 商店 | 杂货店买种子/工具/礼物;卖粮 | 营业时间、价格、好感折扣清晰 | 动态供需 |
| 饭馆/诊所 | 吃饭回体力;诊所处理疲劳/受伤 | 场景可进入、NPC 在岗、服务有效 | 疾病与保险 |
| 送礼 | 每 NPC 喜恶、生日、每日一次 | 送对/送错有不同反应并记录 | 礼物记忆、群体反应 |
| 对话 | 季节/天气/时段/好感/事件后变体 | 每个 NPC 至少 4 季节问候 + 事件后对白 | 关系网对白 |
| 好感事件 | 6 人 × 3 个 = 18 个 | 达到门槛且条件满足时触发;选择写回存档 | 恋爱/家庭线 |
| NPC 日程 | 按时间/季节/天气换位置与行为 | 可直接观察 NPC 在镇上走动、进店、回家 | 路径寻路、节日特殊日程 |
| 任务 | 公告板 + 人物委托 | 接取、完成、交付、奖励、存档 | 长链任务 |
| 节日 | 春耕集市、秋收戏台 | 日期到达、场景布置、NPC 聚集、参与玩法 | 更多节日 |
| 农场扩建 | 木工房购买扩建,地块网格增长 | 存档保留新地块,不丢旧档 | 建筑摆放、畜牧 |
| 矿洞/畜牧/婚姻 | 本轮不做 | 标记为后续路线图 | 单独设计 |

### 7.1 每日核心循环

```text
起床(农舍) → 看天气/邮差 → 照料农场 → 去镇上办事/送礼/接委托
→ 去河岸或树林采集/钓鱼 → 回饭馆吃饭或回家做饭
→ 黄昏触发人物事件/节日 → 回家睡觉 → 日结算
```

### 7.2 季节核心循环

```text
春:整地、播种、赶集、认识人
夏:浇水、除草、钓鱼、修水利、人物中段事件
秋:抢收、秋霜、秋翻、秋收节、人物高光
冬:休耕、室内加工、冬储、走亲戚、戏台、结局式事件
```

## 8. NPC、好感与事件

### 8.1 关系数值

- 好感度 0-100,UI 显示 10 颗心,每颗 10 点。
- 每天第一次对话 +1;送礼每天一次;生日送礼 3 倍。
- 喜欢的礼物 +10,普通 +4,讨厌 -3;事件选择可 ±5~10。
- 不设“长期不联系自动掉好感”,避免惩罚玩家;但事件会受季节和前置 flag 限制。

### 8.2 触发条件

事件条件由数据驱动,至少支持:

- 好感度门槛(20/50/80);
- 季节、月份、星期;
- 时段与天气;
- 地点与 NPC 是否在岗;
- 前置/排除 flag;
- 是否已完成某事件;
- 玩家持有物品或任务进度。

### 8.3 事件结构

每个好感事件不是“一段长对白”,而是四拍:

1. **触发**:玩家在正确时间地点遇到 NPC 的异常行为。
2. **靠近**:玩家选择介入/观察/离开。
3. **选择**:至少 2 个有价值冲突的选择,没有明显“正确答案”。
4. **余波**:事件结束后 NPC 日程、称谓、对白或礼物反应改变;写进存档。

### 8.4 六名核心 NPC

详细人物圣经见 `docs/BZC-人物圣经-v5.md`。设计层锁定:

| NPC | 社会角色 | 表层欲望 | 内层需要 | 3 事件弧线 |
|---|---|---|---|---|
| 张晓芳 | 粮站收购商 | 把账做干净、守住粮站 | 原谅父亲,也原谅自己 | 夜里校秤 → 霜前开仓 → 旧账真相 |
| 韩守义 | 老邮差 | 体面退休、送完最后一班 | 说出藏了半辈子的那封信 | 分拣死信 → 未寄出的信 → 送信/留下 |
| 孙玉梅 | 饭馆老板 | 饭馆一直热闹、儿子回来 | 不再只以“母亲/东道主”定义自己 | 节日帮厨 → 儿子失约 → 交出锅铲/新菜单 |
| 赵长河 | 木匠/修理工 | 修好一切、不再被笑话 | 允许自己再做一件可能失败的新东西 | 修院门 → 扩建犹豫 → 戏台新结构 |
| 林小满 | 卫生所护士 | 考回城里、证明自己没输 | 接受留下或离开都是自己的选择 | 处理伤病 → 城里 offer → 留下/离开分支 |
| 周德顺 | 古戏台守台人 | 再唱一场完整的二人转 | 把技艺交出去,接受听力衰退 | 扫台 → 排练失控 → 最后一个满台 |

### 8.5 人物塑造硬规则

1. 每个 NPC 必须先有“想要什么”和“真正缺什么”,再写台词。
2. 禁止把人物写成农时提示器、商店按钮或背景板。
3. 每个事件至少让玩家看到人物的一处矛盾,而不是只增加信息。
4. 人物之间必须有关系:谁欠谁、谁照顾谁、谁不愿见谁。
5. 选择不能只有“加好感”和“减好感”:要有不同的关系后果与世界后果。

## 9. 美术方向

### 9.1 一句话

> **世界结构对标星露谷,画面质感对标饥荒:3/4 俯视可生活小镇,手绘粗墨线、纸张/木刻肌理、低饱和东北土色盘、四季与天气统一演出。**

### 9.2 不能继续做的事

- 不用整块平涂天空、树冠、地面作为最终画面。
- 不用低分辨率像素块冒充“手绘”。
- 不让 AI 概念图直接进游戏充当可动画角色。
- 不让同一张背景在春夏秋冬只改一个滤镜。

### 9.3 视觉规范

| 项 | 规范 |
|---|---|
| 视角 | 3/4 俯视;建筑与角色保持同一透视 |
| 描边 | 2-3px 暖黑墨线,非纯黑;前景更粗、远景更细 |
| 纹理 | 纸张纤维、木刻排线、干笔擦痕;地面与建筑不可纯色 |
| 色盘 | 每张地图 10-14 色;低饱和土色为主,单点暖色引导 |
| 光 | 统一方向光 + 场景局部光(窗、灶、灯);夜晚蓝灰罩 + 暖窗 |
| 角色 | 剪影优先;每人固定轮廓、步态、常用手部动作 |
| 季节 | 同一地点四套材质/植被/光照/NPC 服装,不是换色 |
| UI | 木、纸、麻布质感;信息层级清楚,不遮挡世界 |

### 9.5 角色与动画规格

- 主角与 NPC:四方向(下/上/左/右),每方向 8 帧行走 + 2 帧待机呼吸。
- 最终游戏资源为**手绘或手绘描摹后再分层上色**,不是 AI 原图缩放。
- NPC 每人至少:基础立绘、头像框、四季服装差分、2 个日常动作(工作/休息)。
- 角色导入前必须通过剪影测试:去掉颜色和五官后仍能认出是谁。

### 9.6 AI 生图工作流

官方 `image_gen` 仍不可用,但项目已通过 MiniMax `image-01` 管线(`tools/ai_imagegen.py` + `tools/generate_ai_assets.py`)生成 22 张概念母版。AI 的定位仍是**概念图和材质母版**,不是最终动画资产:

1. AI 生成四季节关键场景板:春农场、夏河岸、秋玉米地、冬雪镇。
2. AI 生成 3 名代表 NPC 的正面立绘,统一墨线、色盘、材质。
3. 美术把关:检查东北气候是否成立、是否出现现代/西式错误元素、透视是否统一。
4. 将通过的图拆成:色调参考、材质参考、建筑/道具造型参考、角色面部/服装参考。
5. 最终 sprite、瓦片、碰撞、遮挡、动画由确定性管线制作;AI 图只作母版与描摹底稿。

**阶段 0 艺术门**:四季节场景板 + 3 名 NPC 立绘没有通过用户确认,不批量生成其余资产。

### 9.7 画面验收

在 1920×1080 下截取同一地点的春夏秋冬四图,必须满足:

- 能一眼看出季节,不依赖 HUD 文字;
- 地面、树、建筑、天空都有材质层次,没有大面积纯色平涂;
- 角色和背景有同一墨线语言,角色不“贴”在背景上;
- 天气粒子与光照不遮挡交互提示;
- 与饥荒参考并排看,属于同一“手绘暗童话/粗描边”视觉家族,但保留东北小镇的明亮生活感。

### 10.3 输入仲裁

- 世界动作、对话、商店、背包、邮册、暂停全部进入唯一 `ModalStack`。
- 世界场景不自己维护布尔锁;`input_locked = modal_stack.depth > 0`。
- 事件对话期间时钟暂停;关闭全部模态后恢复。

### 10.4 数据驱动

- `npcs.json`:身份、立绘、日程、喜恶、生日、关系、事件索引。

## 13. 验收脚本(必须真正走通)

### 13.1 三天生活闭环

1. 新游戏从农舍醒来,看天气和信。
2. 去农场翻土、播种、浇水。
3. 走到镇中心,进杂货店买种子,和至少 2 名 NPC 说话。
4. 送一次礼物,好感变化写回。
5. 去河岸钓鱼,去树林采集。
6. 回饭馆吃饭,体力恢复。
7. 回家睡觉,日期/天气/作物/好感全部结算。
8. 次日 NPC 位置和日程变化。
9. 保存、退出、读档,状态完全一致。

### 13.2 人物事件闭环

1. 好感达到 20,在指定时段和地点看到 NPC 异常行为。
2. 触发事件,做出选择。
3. 事件 flag 写入存档,次日 NPC 出现新对白或日程变化。
4. 达到 50/80 后触发后续事件;选择不同,结局余波不同。

### 13.3 季节闭环

1. 春播→夏长→秋收→冬歇完整走过。
2. 秋霜未收作物死亡,秋翻地次年有加成。
3. 冬季不能播种,但室内烹饪/冬储/人物事件可用。
4. 四季环境肉眼可辨,截图可验收。

## 14. 风险与对策

|---|---|
| 内容量过大 | 按 M0-M5 分批,每批可玩、可验收;不一次性铺完 |
