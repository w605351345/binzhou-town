# 《麦溪镇》西境农庄重构设计

> 状态：已批准并进入实施（用户明确要求“中间不设置门禁”）
> 版本：2026-11-14

## 1. 目标

把当前偏东北民俗、俯视色块、长周期农时的版本，重构为一款明亮、可爱、可读性强的西式田园生活 RPG：

- **75% 种田**：短周期作物、清晰的地块反馈、日常农事循环、农场扩建与出货。
- **5% 旅行青蛙**：轻量寄信、远方回信、旅行见闻收藏，不抢占主循环。
- **20% 古代戏剧本**：月桂剧场的古戏剧本、排练选择、公演评价与人物关系变化。
- 完全取消东北地域符号（火炕、二人转、酸菜、苞米楼子、黑土地话术等）。
- 视觉参照《星露谷物语》的亲和力与可读性，但使用本项目自己的西式田园设定与 AI 手绘母版。

## 2. 世界与叙事

- 地点：**麦溪镇（Meadowbrook）**，山谷中的西式农庄小镇。
- 玩家继承外祖父留下的旧农场，在镇民帮助下重新经营。
- 主舞台：农场、镇中心、河湾、柳林、月桂剧场、北山矿洞、牧场、镇史馆。
- 古戏剧本不是独立小游戏，而是 20% 的叙事骨架：镇民各自带着一段未说完的旧戏，玩家通过农事与社交收集戏页，在月桂剧场排练并决定演出结局。

## 3. 可玩性指标

| 指标 | 目标 |
|---|---|
| 第一天可完成 | 翻地 → 播种 → 浇水 → 睡觉 → 第二天看到生长 |
| 首个可收获作物 | 4-5 个游戏日 |
| 单游戏日现实时长 | 约 7-9 分钟 |
| 农场出口 | 从出生点可无碰撞走到南门，门有明确视觉引导 |
| 近距离提示 | 距 NPC / 门 / 互动物 140px 内才出现 |
| NPC 可见性 | 默认开局镇中心至少 1 名可交谈 NPC |
| 农田占比 | 主线任务、奖励、界面信息优先农业 |
| 剧本占比 | 每 2-3 个农事日推进一段戏页/排练/公演 |
| 明信片占比 | 每天至多 1 封，不产生强制日常 |

## 4. 视觉规范

- 明亮饱和但不刺眼：草绿、奶油石、蜂蜜木、野花黄、河水蓝。
- 角色：大头小身、清晰眼睛、圆润轮廓，4 方向行走可读。
- 场景：道路、门槛、可互动区域必须有视觉区别，但禁止满屏标签和交互光环。
- UI：顶部只保留日期/天气、地点、金币/体力；底部提示仅在靠近目标时滑入。
- AI 图：用于主菜单、地点概念板、人物立绘、地表材质母版；运行时布局与碰撞仍由数据驱动。

## 5. 核心循环

```text
起床 → 看天气/信箱 → 照料 3-6 块地 → 去镇上卖货/接委托
→ 与镇民交谈、收集戏页 → 傍晚排练或寄信 → 回家睡觉
```

每 7 天形成一个小目标：收获一批作物、完成一张委托、推进一幕古戏。

## 6. 系统边界

- 不引入联网、账号、付费或第三方运行时依赖。
- 保留现有数据驱动地图、存档迁移、键鼠与手柄输入。
- 保持 Godot 4.3 与 macOS/Windows 导出能力。
