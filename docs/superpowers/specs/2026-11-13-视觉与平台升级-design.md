# 《宾州小镇》视觉与平台升级 —— 设计文档

日期:2026-11-13 · 状态:**已批准并实施(2026-11-13)** · 关联:企划 v4.0 / 进度追踪 v4.3

---

## 1. 意图与背景

玩家反馈当前画面难看,提出五项要求:美术向《饥荒》靠拢、NPC 改名、配普通话语音、背景按真实地形优化但游戏内不提真实地名、支持 Windows/mac 安装版与 Steam 手柄。

体检结论(截图证据 `docs/screenshots/before/`):

| 现状 | 证据 |
|---|---|
| 背景是整块平涂色 | `farm_v1.png` 一片草绿,`town_v1.png` 一片土黄,无天空/地平线/远景 |
| 角色是几何图元 | 张婶 = 深色方块身体 + 肤色圆头;主角 32×48 像素,占屏高 4% |
| 几乎没有描边 | 只有地块有 1px 边框,其余全无 —— 饥荒最标志性的特征缺失 |
| 地块布局越界 | 3×3 网格以世界原点居中,渲染到屏幕左侧外,9 块只露 2 块(**真 bug**) |

中文渲染正常(Godot 自动回退系统字体),问题纯粹在美术,不在字体。

**环境硬约束(影响做法,已验证)**
- 本机下不到 Godot 导出模板 → **本地无法产出安装包**,只能写好预设 + 由 CI 构建
- 本机无 `image_gen` 工具、无 `OPENAI_API_KEY`、`api.openai.com` 不通 → **不能用 AI 生图**,美术只能程序化生成
- 无 ffmpeg,但有 macOS `afconvert`;`say -v Tingting` 可生成普通话音频并转 wav(Godot 原生支持)

## 2. 目标 / 非目标 / 反目标

**目标**
1. 画面观感达到"手绘感剪影 + 粗描边 + 暖土色盘 + 分层背景",与《饥荒》同一观感家族
2. 全局统一美术规范,后续真实美术资源到位后可逐件替换,不改代码
3. 张晓芳(改名后)有专属立绘与声线,不再用"婶/姨"称谓
4. 普通话语音包覆盖全部对话,并有字幕与音量开关
5. 场景地貌取自真实地形要素,游戏内不出现任何真实行政区划名
6. Windows/mac 双平台可发布包 + 手柄可玩 + Steam Deck 兼容

**非目标**
- 不追求商业手绘水准(环境无 AI 生图与美术外包,程序化生成有上限)
- 不做安装向导(Windows Installer / macOS dmg)—— Steam 上架用 Godot 官方包即可,做安装器收益低
- 不接 Steamworks SDK(GodotSteam)—— 需要发行方账号权限,放在 Week 6 做 Steam Cloud 时一并评估
- 不改玩法数值、作物表、农时规则(本轮纯表现层 + 平台层)

**反目标**
- 不引入新的第三方 GDScript 插件(全部自研,保持零依赖)
- 不用网络下载美术/字体资源(打包进仓库,CI 可复现)

## 3. 美术方案(核心)

### 3.1 风格规则

| 规则 | 具体值 | 对应饥荒特征 |
|---|---|---|
| 粗描边 | 所有物件轮廓 2–3px,暖黑 `#241a12`(非纯黑) | 手绘描边 |
| 有限色盘 | 每场景 8–12 色,低饱和暖调,集中定义在 `ArtPalette` | 统一调色 |
| 有机轮廓 | 形状由贝塞尔 + 噪声扰动生成,禁用纯圆/纯方 | 手绘不规则 |
| 纸片分层 | 背景 3–4 层:天空 → 远景 → 中景 → 地面;远景向天空色靠拢(大气透视) | 剪纸层次 |
| 实心阴影 | 脚下椭圆软阴影 + 物件底部暗部 | 角色落地感 |
| 前景高光 | 上缘 1px 暖色高光,下缘 1px 暗部 | 手绘笔触 |

### 3.2 产出物(程序化生成,Python 无依赖手写 PNG 编码器,沿用 `tools/gen_sprites.py` 套路)

| 资源 | 规格 | 说明 |
|---|---|---|
| 主角精灵表 | 48×72/帧,3 向 × 8 帧 | 手绘轮廓;实高约 60px,约为地块的 2/3 |
| 张晓芳精灵表 | 48×72/帧,3 向 × 8 帧 | 与主角同尺寸,玫红棉袄 + 围裙 |
| 作物 | 9 种 × 3 阶段 | 出苗/成长/成熟 |
| 道具 | 12 件 | 种子/工具/吃食 |
| 地块 | 5 张土壤贴图 | 荒草/翻土/出苗/成熟/休耕 |
| 背景 | 农场 3 层 + 镇大街 3 层 | 天空/远景/地面分离成图 |

### 3.3 取景与布局(修地块 bug)

**取景口径**:美术向饥荒靠拢,但**构图保持单屏**(饥荒是近景滚动,本项目 3×3 农场是星露谷式单屏 —— 改相机行为会动玩法,不在本轮范围)。

| 项 | 值 | 说明 |
|---|---|---|
| 基准分辨率 | 保持 1920×1080 | 三个 `.tscn` 的 UI 偏移都按此写死,不改 |
| 相机 zoom | 2.0 | 可视世界 = 960×540 |
| 世界设计尺寸 | 960×540 | `WorldMap` 边界由 1920×1080 改为 960×540 |
| 主角精灵 | 48×72 世界单位(实高约 60) | 屏占高 60/540 ≈ 11%;地块 88px,人约为地的 2/3 |
| 地块 | 96×96,间距 120 | 3×3 = 408×408,在 960×540 里居中 |
| 相机 | 固定(锁整个院子/整条街) | 单屏场景不需要跟随,避免"地块切屏" |

**地块 bug 修法**:地块网格改为相对世界中心 (480, 270) 居中,并重排院子的固定陈设(院墙、柴垛、鸡舍、水井)——这一项同时服务第 6 条的地貌需求。

**字体**:本机无任何可再分发的开源中文字体(下载受限),故**沿用系统字体回退**(macOS 苹方/冬青黑,Windows 雅黑)。手绘感由美术承担,不靠字体。代码预留 `assets/fonts/` 与主题资源:日后美术提供授权字体,放入即生效,不改代码。

### 3.4 UI 改造

对话框/商店/背包面板:深褐羊皮纸底 + 2px 暖色描边 + 圆角,替换现有半透明黑底;按钮增加悬停/按下态描边变化。

### 3.5 接入范围(阶段1 = 资源 **+ 接进游戏**,不是只出图)

只出 PNG 不改场景是验收不了的 —— 阶段0 的截图也必须先跑通接入链路才出得来。故本轮接入:

| 对象 | 替换现有实现 |
|---|---|
| 地块 | `farm_plot_view.gd` 的 `draw_rect` → 土壤贴图 Sprite2D(5 张状态图) |
| 作物 | `_draw_sprout` / `_draw_ready` 的几何图元 → 作物精灵(9 种 × 3 阶段) |
| 角色 | `npc_node.gd` 的 `_draw` 方块 → 精灵(张晓芳 4 向 × 2 帧站立循环) |
| 背包/商店 | 纯文字 Label → 图标格子(12 件道具 + 9 种作物 + 6 项冬季产出) |
| 主菜单 | 占位文字 → 双立绘 + 饥荒风标题栏 |
| HUD / 暂停菜单 | 面板风格统一 |
| 背景 | 纯色 ColorRect → 三层背景(天空/远景/地面) |

**张晓芳不做巡逻 AI**:她现在原地不动,本轮只做 **4 向 × 2 帧站立呼吸动画**,不引入寻路(超出"只改表现层")。季节变化只换配色,不出 4 套图。

## 5. 语音(普通话)

- **管线**:`tools/gen_voice.py` 读 `dialogues.json` → 调 `say -v Tingting` 生成 aiff → `afconvert` 转 22050Hz 单声道 wav → 存入 `assets/voice/<npc_id>/<voice_key>.wav`
- **音频键值(必须永久稳定,否则"真人录音覆盖同名文件"不成立)**:
  - `texts` 变体加显式 `id`(如 `greet_spring` / `greet_summer`),不再靠数组下标
  - `options` 也加显式 `id`(如 `opt_sow`)
  - 音频文件名 = `<npc_id>/<line_id>__<variant_id>.wav`;无变体时 = `<npc_id>/<line_id>.wav`
  - 校验器强制:变体 id 全局唯一、音频文件与数据一一对应(缺文件报错、多文件报错)
- **覆盖范围**:NPC 台词 + 关键系统提示(季节播报、商店/背包提示语);玩家选项不配音
- **播放**:`VoicePlayer` autoload,按行 id 播放;对话推进时同步打逐字字幕(打字机效果),E/空格可快进
- **替换成本**:真人录音只需覆盖同名 wav,无需改代码
- **开关**:暂停菜单加"语音音量"滑条与"关闭语音"开关
- **企划同步**:D11 决策从「暂不支持配音」改为「支持普通话语音(占位用 TTS,后期换真人录音)」,`docs/宾州小镇_完整游戏企划_v4.md` §8.1 同步修订

## 7. 平台与手柄

### 7.1 导出

- 新建 `export_presets.cfg`(**同时从 .gitignore 移除该条目**,当前被忽略会导致 CI 无预设可用):Windows Desktop(.exe)、macOS(.zip/.app)、Linux(已有)

- 本机无模板 → **本地只验证预设语法与场景冒烟,实际安装包由 CI 出**

### 7.2 手柄映射

| 动作 | 键盘 | 手柄 |
|---|---|---|
| 移动 | WASD | 左摇杆 / 十字键 |
| 交互 / 确认 | E / 空格 | A(底部) |
| 工具:翻土 / 浇水 / 播种 / 收获 / 秋翻 | J K L I R | RB / LB / X / Y / RT |
| 睡觉 | T | 选择(Start) |
| 切换地点 | F | 摇杆按下(L3) |
| 背包 | TAB | 视图键(顶部) |
| 暂停 | ESC | 菜单键(Start 侧) |
| 关闭当前面板 | ESC | B(右侧) |

**三处冲突的裁法**
1. Y(顶部) 与浇水冲突 → 工具全部挪到肩键/面部键,Y 归背包
2. B 与 ESC 冲突 → `ui_cancel` 保留 B(仅用于关面板),**暂停单独绑 Start 侧菜单键**,ESC 只在无面板时生效
3. 十字键/左摇杆与菜单导航冲突 → 角色移动与 `ui_*` 共用同一批键位;**打开面板时 `input_locked` 锁住角色移动**,菜单导航照常。已有的 `input_locked` 机制正好闭环,无需额外改 `ui_*`

- 背包/商店的按钮列表需要焦点导航:打开面板时给第一个按钮 `grab_focus()`,`ui_up/down` 即可切换
- 提供 `steam_controller_x.txt`(Steam Input SDL 映射模板)+ 配置说明;**Steamworks 账号尚未注册、拿不到 App ID,本轮只交文件与说明,无法实机验证**
- 新增自测:输入映射存在性检查(全部动作都绑了 joypad 事件)
