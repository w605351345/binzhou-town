# 麦溪镇体验优先与内容扩展实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在基础春季垂直切片之上，先把移动手感、交互可见性、画面亮度、音频与路面精度打磨到可验收，再补充《灯火归溪》主线、五类资源采集、工具升级、农场建造和淡水/海水钓鱼。每个任务都必须能独立测试、独立提交、独立回滚。

**Architecture:** `MainlineSystem`、`ResourceNodeSystem`、`PlacementSystem` 保持纯逻辑；`LocationScene` 只收集交互候选并驱动表现。资源、建造与主线状态统一进入 `GameState`，存档迁移兼容 v3 与 v4，最终提升到 v5。钓鱼在现有 `FishingSystem` 上扩展为“水域 × 天气 × 季节 × 鱼竿等级 × 稀有度”筛选。

**Tech Stack:** Godot 4.3、GDScript、JSON 数据表、Python 数据校验与资源生成、headless 测试、macOS/Windows 导出。

**Spec:** `docs/superpowers/specs/2026-11-16-整体设计重构-design.md` 第 17 章

## 执行顺序与阶段门

- **阶段 A（Task 1–7，体验门）**：先修时间、手感、提示、可见性、亮度、头像/音频和路面。阶段门未通过，不进入内容扩展。
- **阶段 B（Task 8–9，主线）**：依赖基础计划的 `LetterSystem`、`DramaSystem`、`SpringSlice`；基础计划尚未实现时，先完成其 Task 10–13。
- **阶段 C（Task 10–13，采集与工具）**：建立资源数据、节点冷却、工具等级和统一交互。
- **阶段 D（Task 14–15，建造）**：只在 L01 农场放置，先完成逻辑再完成预览与碰撞。
- **阶段 E（Task 16–18，钓鱼）**：先做筛选与稀有度，再开 L15 海潮湾，最后接 UI、鱼竿与主线进度。
- **阶段 F（Task 19–20，存档与发行）**：先完成 v5 迁移，再做全量回归、验收文档和本地打包。
- 阶段 A 可以立即在现有分支执行；阶段 B–F 不得跳过阶段 A 的体验门。
- 每个任务结束提交一次；不提交 `docs/screenshots` 下的历史截图目录。

## Global Constraints

- 单日现实时长固定为 25 分钟：`REAL_SECONDS_PER_GAME_MINUTE = 1.25`，06:00–26:00 共 1500 现实秒。
- 视觉继续使用纸上剧场；新增 UI 必须使用 `PaperTheme`，提示默认是纯文字或轻纸卡，不得新增黑色半透明大横条。
- NPC 语音保持关闭，暂停菜单不再暴露可误开的语音开关；不同场景使用不同背景音乐。
- 角色对话必须显示与运行时角色同一设计的头像；头像生成使用 `~/.codex/minimax.config.toml` 的 MiniMax 配置，密钥不进入仓库。
- 主线进度必须由真实系统事件写入，禁止独立假计数器；章节奖励在完成后次日送到农场信箱，只能领取一次。
- 资源分木材、矿石、植物、瓜果、鱼类五类；工具分别为 `axe`、`pickaxe`、`sickle`、`harvest_basket`、`fishing_rod`。
- 工具等级 1–3；每级同时提供数值增强与资源门槛解锁。
- 建造首版仅限 L01 农场；64×64 网格吸附；不允许重叠建筑、水、门、NPC 固定路线与已有建造物。
- 主路宽 192/256 像素，支路至少 128 像素；道路边缘、门口、桥头和建造格必须落在 64 像素网格。
- 钓鱼水域为 `freshwater` 与 `saltwater`；天气至少覆盖晴天与雨天；稀有度四档：`common`、`uncommon`、`rare`、`legendary`，稀有度越高价值越高。
- 新增 L15 海潮湾，从 L09 河湾双向进入，使用独立 `coast` 配乐。
- 存档必须兼容 v3、v4 与 v5；旧农场、牲畜、矿洞、收藏、关系、任务、节日、明信片、戏剧与语音字段不得丢失。
- 所有功能先写失败测试，再写实现；测试命令必须可在 headless 环境复现。

## Review Focus

- 移动：起步、停止、斜向、反向输入和贴墙滑行是否仍有卡顿；门口与碰撞边缘是否会把角色夹住。
- 可读性：提示是否仍出现黑边；NPC、门口、资源节点和建筑身份是否会被场景遮挡或融进背景。
- 主线：奖励是否重复领取、提前领取、跨日未送达仍可领取；读档后是否重复发奖。
- 采集与建造：错误工具、等级不足、重复采集、重叠放置、拆门堵路和读档冷却是否正确。
- 路面与钓鱼：视觉路面是否与碰撞通行边界一致；淡水/海水、天气、季节、鱼竿等级是否混池；稀有鱼价值是否倒挂。

## File Structure

**体验与表现**
- `scripts/player/player_controller.gd`、`scripts/player/player.gd`：移动加速度、停止与碰撞反馈。
- `scripts/ui/game_hud.gd`、`scripts/world/location_scene.gd`、`scripts/world/focus_marker.gd`：纯文字提示、交互高亮与可见性。

- `scripts/ui/dialogue_box.gd`、`scripts/audio/music_director.gd`：头像框、语音关闭与场景配乐。
- `scripts/world/map_database.gd`：`road_audit`、门洞净宽和碰撞审计。

**主线**
- `data/mainline.json`：6 章目标、资源奖励、前置章节。
- `scripts/core/mainline_system.gd`：章节推进、事件去重、奖励送达与领取。
- `scripts/ui/mainline_panel.gd`、`scripts/ui/game_hud.gd`：章节列表、当前目标与信箱提醒。
- `scripts/world/location_scene.gd`、`data/maps.json`：L01 农场信箱互动。

**资源与工具**
- `data/items.json`、`data/resource_nodes.json`、`data/tool_upgrades.json`：资源、节点和工具门槛。
- `scripts/resources/resource_node_data.gd`、`scripts/resources/resource_node_system.gd`：节点读取、冷却与采集。
- `scripts/world/resource_node_view.gd`：树桩、矿脉、草药、果丛等纸片造型。
- `scripts/services/tool_upgrade_system.gd`：1–3 级工具与资源门槛。

**建造**
- `data/buildables.json`：占用、碰撞、道具与作用。
- `scripts/building/placement_system.gd`：64 格吸附、重叠检查、拆除与存档。
- `scripts/building/placement_renderer.gd`、`scripts/ui/build_panel.gd`：预览三态、已放建造物与面板。

**钓鱼与海潮湾**
- `data/fish.json`：水域、天气、季节、稀有度、价值、鱼竿等级。
- `scripts/activities/fishing_system.gd`：筛选、权重、稀有度与结果。
- `scripts/ui/fishing_panel.gd`：水域、天气、季节与可钓等级。
- `data/maps.json`、`scenes/locations/L15.tscn`、`scripts/ui/scene_router.gd`：海潮湾。
- `assets/audio/music/coast.wav`、`tools/gen_music.py`：海潮湾配乐。

**存档与回归**
- `scripts/core/game_state.gd`、`scripts/core/save_migrator.gd`：v5 字段、v3/v4 迁移。
- `scripts/tests/test_mainline.gd`、`test_resources.gd`、`test_building.gd`、`test_fishing_v2.gd`、`test_interaction_priority.gd`、`test_gameplay_polish.gd`：新增回归。
