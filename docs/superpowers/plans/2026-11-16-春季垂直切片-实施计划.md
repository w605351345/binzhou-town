# 麦溪镇春季垂直切片实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在保留现有 Godot 数据与存档骨架的前提下，完成阶段 0–2，交付一个视觉统一、可连续游玩 14 个春季日、并跑通信件与月桂戏台主循环的《麦溪镇》垂直切片。

**Architecture:** 继续使用 `LocationScene + MapDatabase + JSON 数据` 驱动世界，在现有 HUD、对话、戏剧与存档系统上增加纸张主题、春季切片编排、世界内信件和选角/公演状态。所有新规则先写成 headless 可测的 RefCounted 系统，再由地点场景与 UI 接线。垂直切片只改 L01、L03、L05、L06、L11 与三名核心 NPC，不批量重做 14 张地图和 11 名角色。

**Tech Stack:** Godot 4.3、GDScript、JSON 数据表、Python 资源生成/校验脚本、现有 headless 测试与导出流程。

**Spec:** `docs/superpowers/specs/2026-11-16-整体设计重构-design.md`

## Global Constraints

- 世界为架空西式河谷小镇，界面、对白、信件和任务均使用简体中文；NPC 显示名使用西方名字的中文化写法，内部 ID 永不变。
- 视觉统一为“纸上剧场 / Paper Theatre”：纸白、墨褐、水粉笔触、墨线描边、纸纹，不使用大面积黑色半透明横条。
- 基准分辨率 1920×1080；世界网格 64×64；角色画布 96×144；角色约 3.5 头身；默认镜头屏幕高度 130–150 像素。
- 玩法优先级为农场与日常生活 50%、小镇社会与人物 30%、信件与月桂戏台 20%。
- 垂直切片固定为春季 14 天；三个核心 NPC 为 `zhang_xiaofang`、`han_shouyi`、`zhou_deshun`。
- 垂直切片必须包含：农场种田闭环、镇中心 3 名 NPC、1 家商店、1 个邮局委托、1 段人物事件、1 幕月桂戏、1 个节日。
- 第一幕必须包含“发现剧本 → 初次选角 → 3 个舞台节点的小型公演”；公演采用舞台指挥式选择，不做自由走位。
- 信件必须在世界内投递；投递、退回和私下阅读状态必须写入存档；同屏最多携带 3 封。
- NPC 语音保持关闭，对白只显示字幕；不同场景继续使用不同背景音乐。
- 旧存档必须保留关系、任务、节日、明信片、农场、牲畜、矿洞、收藏与旧古戏进度。
- 不新增联网、账号、第三方运行时依赖；保持 macOS 与 Windows 可导出。
- 每个任务结束必须提交一次；不得把 `docs/screenshots` 下的历史截图批量提交。
- 运行测试前先执行 `godot --headless --import --quit`；新增 GDScript 系统必须有 headless 测试。

## Review Focus

- 旧存档加载：缺少 `letters`、`slice` 或新戏剧字段时，不能让关系、任务、节日、明信片、农场、牲畜、矿洞、收藏或已完成古戏丢失。
- 信件边界：重复投递、投错人、携带已满、错过投递窗口、私下阅读后再投递、退回后再领取，都必须有确定且不破坏存档的结果。
- 选角边界：无效 NPC、重复选角、未完成选角就开演、公演中重复选择同一节点、旧戏进度映射后重演，都必须被拒绝或安全处理。
- 世界文本口径：内部 ID、门目标、地图引用保持不变；任何玩家可见文本不得再出现“张晓芳、韩守义、孙玉梅、赵长河、林小满、周德顺、石铁山、江牧云、何水根、苏文博、郎三顺”。
- 单日节奏：用户已确认“时间流速过快”的反馈；本计划不把时钟调快，保持 0.9 秒/游戏分钟（约 18 分钟/日），通过缩小地图和减少空走来达到设计中的有效游玩时长。

## File Structure

**数据**
- `data/npcs.json`：11 名 NPC 的稳定 ID、西方中文化显示名、身份、日程与资产路径。
- `data/maps.json`：L01/L03 原型地图与五类垂直切片地点的地形、建筑身份、碰撞、门和互动点。
- `data/asset_spec.json`：角色、建筑、立绘与切片资产的尺寸和验收范围。
- `data/letters.json`：可领取信件、收件人、投递窗口、文本与后果。
- `data/spring_slice.json`：春季 1–14 日的里程碑、指引、信件投放与事件编排。
- `data/drama.json`：第一幕《河湾记得》的选角角色、候选人与 3 个舞台节点。
- `data/events.json`：垂直切片的一段人物事件。
- `data/festivals.json`：调整后的春播集市。

**核心逻辑**
- `scripts/core/game_state.gd`：新增 `letters`、`slice` 与戏剧状态的安全默认值。
- `scripts/core/save_migrator.gd`：存档 v4 迁移与新字段默认值。
- `scripts/core/spring_slice.gd`：14 日切片状态、里程碑、当日指引和信件投放。
- `scripts/core/guidance_system.gd`：切片进行中时优先返回切片指引。
- `scripts/letters/letter_data.gd`：读取 `letters.json`。
- `scripts/letters/letter_system.gd`：领取、携带、投递、退回、阅读和关系后果。
- `scripts/drama/drama_system.gd`：选角、选角条件、文本替换、公演状态与结果。

**表现与 UI**
- `scripts/ui/paper_theme.gd`：统一色板、字体、纸张卡片、印章按钮与标签角色。
- `scripts/ui/paper_grain_overlay.gd`：世界纸纹层。
- `scripts/ui/tool_bar_view.gd`：底部快捷工具栏与当前上下文动作。
- `scripts/ui/letter_panel.gd`：邮局柜台内的携带信件与阅读/退回面板。
- `scripts/ui/game_hud.gd`：纸张 HUD、信件面板接线、切片指引。
- `scripts/ui/dialogue_box.gd`：纸张对话框与统一头像框。
- `scripts/ui/drama_panel.gd`：选角与公演界面。
- `scripts/world/location_scene.gd`：世界内投递提示与接线。
- `scripts/world/map_renderer.gd`：建筑身份、纸张地形细节和公演后的海报装饰。
- `scripts/npc/npc_node.gd`：96×144 角色帧、常驻名牌和身份道具。

**测试与工具**
- `scripts/tests/test_paper_ui.gd`：主题、HUD、对话框、纸纹和工具栏。
- `scripts/tests/test_letters.gd`：信件数据、携带上限、投递、阅读、退回和存档。
- `scripts/tests/test_spring_slice.gd`：14 日编排、节日、时间流速和指引。
- `scripts/tests/test_art.gd`、`test_world.gd`、`test_drama.gd`、`test_save_v2.gd`、`test_gameplay_polish.gd`、`test_playability.gd`：扩展现有回归。
- `tools/validate_identity.py`：命名与世界文本口径校验。
- `tools/gen_art.py`、`tools/generate_ai_assets.py`、`tools/capture_scenes.py`：纸张素材、MiniMax 头像和截图证据。
