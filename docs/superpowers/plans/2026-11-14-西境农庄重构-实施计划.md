# 西境农庄重构实施计划

**Goal:** 修复实际游玩阻断，并把游戏重构为 75% 种田 / 5% 旅行青蛙 / 20% 古代戏剧本的西式田园体验。

**Architecture:** 保留现有数据驱动地图与系统分层；先修移动/交互/时间等底层，再替换文案与美术，最后补古戏剧本与轻量旅行系统并做双平台打包。

**Tech Stack:** Godot 4.3 / GDScript / JSON 数据 / Python 资源管线 / MiniMax image-01。

**Spec:** `docs/superpowers/specs/2026-11-14-西境农庄重构-design.md`
